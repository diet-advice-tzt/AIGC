【1】远程连接服务器
-------------------------------------------------------
ssh root@8.141.102.173


【2】上传部署文件（在本地电脑执行）
-------------------------------------------------------
# Windows PowerShell
scp -r race-app root@8.141.102.173:/opt/

# 如果提示权限问题，先创建目录
ssh root@8.141.102.173 "mkdir -p /opt/race-app"


【3】一键部署（在服务器上执行）
-------------------------------------------------------
# 进入部署目录
cd /opt/race-app

# 运行一键部署脚本
bash deploy/deploy.sh 8.141.102.173


【4】手动部署（备选方案）
-------------------------------------------------------
# 1. 安装依赖
curl -fsSL https://rpm.nodesource.com/setup_20.x | bash -
yum install -y nodejs nginx
npm install -g pm2

# 2. 安装后端依赖
cd /opt/race-app/server
npm install --production

# 3. 启动服务
pm2 start ecosystem.config.js
pm2 startup
pm2 save

# 4. 配置 Nginx
systemctl restart nginx


【5】访问应用
-------------------------------------------------------
前端页面: http://8.141.102.173
后端API:   http://8.141.102.173/api
健康检查:  http://8.141.102.173/api/health


【6】管理命令
-------------------------------------------------------
pm2 status          # 查看服务状态
pm2 logs race-server # 查看日志
pm2 restart race-server # 重启服务
systemctl status nginx # 查看 Nginx 状态


【7】配置安全组（阿里云控制台）
-------------------------------------------------------
需要开放以下端口：
- 80    (HTTP)
- 443   (HTTPS)  
- 8080  (后端服务)


【8】配置 API Key
-------------------------------------------------------
# 编辑环境变量文件
nano /opt/race-app/server/.env

# 设置您的 DashScope API Key
DASHSCOPE_API_KEY=sk-您的API密钥

# 重启服务
pm2 restart race-server
